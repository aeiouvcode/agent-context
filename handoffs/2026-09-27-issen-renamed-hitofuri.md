# ISSEN renamed HITOFURI

Date: 2026-09-27 17:05 IST (owner decision, relayed by main)
Author: Instinct (gardener)

## What
The ISSEN game is renamed HITOFURI (一振り, "one swing of the sword").

## Why
Name collision: "ISSEN: Samurai Slash" (PixelRyu) is live on the iOS App
Store (apps.apple.com/us/app/issen-samurai-slash/id6772437281) and Google
Play, on the same one-cut sumi-e concept; "Ninja Issen" exists on Steam.
HITOFURI was clear on all three stores at shortlist time (2026-09-27).

## Repo name stays
aeiouvcode/issen KEEPS its name for now - a repo rename would break existing
links, CI workflow references, and live release URLs (e.g. the dbgprobe-v3
probe APK the owner is using for on-device captures). The game title and
store-facing branding move to HITOFURI; code/internal names migrate as the
hub touches them.
