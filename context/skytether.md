# SKYTETHER — open-world rope-swing city game

Procedural city, pendulum rope physics, original heroes. Mechanics inspired
by a Three.js web-swinging video; no Spider-Man IP.

## Facts
- Repo: `github.com/aeiouvcode/skytether` — live at
  `aeiouvcode.github.io/skytether`.
- Single HTML file; city generated in code. Heroes: "Tether" (web track),
  "Rook" (Godot branch).
- Systems: pendulum rope physics, wall runs, traffic, crime events, district
  unlocks.
